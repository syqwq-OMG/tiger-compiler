Hints 

1. `tr::Exp != tree::Exp`
2. For escape analysis, you'll have to implement the `Traverse` method in various classes of your AST. The purpose of this method is to walk through the tree and apply escape analysis, marking which variables escape their scope. If the variable is found and its depth is less than the current depth, it means the variable escapes (i.e., is used outside its scope). Then you should mark escape as true in the `EscapeEntry`. Moreover, when there's no variable involved, no action is needed. 
3. For the `Level` class defined in `translate.h`: Function `Formals()` provides a way to retrieve the formal parameters of the current function's frame, transforming them into a list of `tr::Access` objects that allow access to those parameters. 
4. When a new function is entered, a new frame is needed. So function `NewLevel()` is used to create a new Level (i.e., a new function activation record), set up a new frame for the function and manage the static link between the current function and its parent function. The static link helps in accessing the variables of the parent function in the case of nested functions or closures.
